🧬 BioNexus — Interactive Biotech Website

A premium, animation-driven biotechnology landing page combining 3D visualization, AI, computational biology, and modern frontend design.

🎯 Why I Built This

I wanted to create a biotech website that feels scientific, futuristic, and interactive rather than like a traditional static website.
